# Experiment 2 – Multi-Layer Perceptron for Fashion-MNIST

## Objective
Implement a Multi-Layer Perceptron (MLP) using TensorFlow/Keras for Fashion-MNIST image classification and perform hyperparameter optimization using RandomizedSearchCV.

## Technologies Used
- Python
- TensorFlow / Keras
- SciKeras
- Scikit-learn
- NumPy
- Matplotlib

## Results
- Baseline MLP model
- Hyperparameter tuning using RandomizedSearchCV
- Confusion Matrix
- Classification Report
- Accuracy, Precision, Recall, and F1-score evaluation
